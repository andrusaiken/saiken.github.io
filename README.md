# SAIKEN — portfólio de editor de vídeo

Site de portfólio de Saiken (André Santos), editor de vídeo focado em gameplay para YouTube.

- Página única em `index.html` (HTML, CSS e JavaScript, sem dependências).
- Visual pixel-pop em colagem, com português e inglês (botão PT / EN).
- Para publicar no GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
