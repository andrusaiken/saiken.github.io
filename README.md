# ⚡ SAIKEN — Portfólio de Editor de Vídeo

Bem-vindo ao repositório oficial do meu portfólio!

Este projeto foi criado para apresentar meu trabalho como editor de vídeo, reunindo minhas habilidades, meu estilo de edição e minha experiência com conteúdo audiovisual.

Meu foco é transformar ideias em vídeos que prendam a atenção, transmitam emoções e criem uma conexão com o público.

## 👤 Sobre o projeto

O portfólio foi desenvolvido para apresentar meus trabalhos de edição, com foco especial em vídeos de gameplay para YouTube, além de projetos que exploram ritmo, narrativa, humor e identidade visual.

A proposta é mostrar não apenas o resultado final, mas também minha forma de pensar a edição e utilizar recursos audiovisuais para contar histórias.

## 🎬 Especialidades

- Edição de vídeos para YouTube.
- Edição dinâmica para Shorts, Reels e outros vídeos curtos.
- Storytelling e construção narrativa.
- Motion graphics e elementos visuais.
- Ritmo, sonorização e sincronização musical.
- Edição voltada para entretenimento e criação de conteúdo.

## 🛠️ Tecnologias utilizadas

O site foi desenvolvido utilizando:

- **HTML5:** estrutura das páginas.
- **CSS3:** estilos, animações e identidade visual.
- **JavaScript:** interatividade e funcionalidades.

O projeto foi desenvolvido como uma página única, sem dependências externas obrigatórias.
